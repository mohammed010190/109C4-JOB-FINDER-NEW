# 109C4 JOB FINDER — Clean start

## التشغيل والنشر
1. أنشئ مستودع GitHub جديدًا باسم `109C4-JOB-FINDER-NEW`.
2. ارفع محتويات هذا المجلد مباشرة إلى جذر المستودع.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.

## مصدر الوظائف
يستخدم التطبيق واجهة Dev Global Jobs العامة: `GET https://devglobaljobs.com/api/v1/jobs`.
لا يحتاج API key. الحد المنشور 120 طلبًا/دقيقة. يجب إبقاء رابط "Powered by Dev Global Jobs" ورابط صفحة كل وظيفة. الاستخدام المجاني مخصص للاستخدام الداخلي والبحثي وغير التجاري؛ راجع الشروط قبل أي استخدام تجاري.

## ملاحظات الدقة
- تاريخ النشر يعرض فقط إذا وفره المصدر.
- البريد يعرض فقط إذا كان ضمن بيانات الإعلان.
- فلتر المدينة يطابق نص الموقع المعاد من المصدر؛ ليس تحديدًا جغرافيًا ذكيًا.
- الحفظ محلي على نفس المتصفح والجهاز في هذه النسخة؛ لا يوجد تسجيل دخول أو مزامنة سحابية بعد.
